Привет, я хочу чтоб ты изучил вот этот документ https://github.com/open-telemetry/opentelemetry-collector-contrib/blob/main/pkg/ottl/LANGUAGE.md
Он является описанием DSL (domain specific language) для обработки сигналов телеметрии.
Основываясь на этом документе я хочу чтоб ты сгенерировал и сохранил в папке проекта файл OTTL.ebnf.
Файл OTTL.ebnf должен содержать максимально полное описание DSL OTTL в расширенной нотации Бэкуса — Наура  
Для справки по нотации Бэкуса — Наура используй следующее описание https://en.wikipedia.org/wiki/Extended_Backus%E2%80%93Naur_form
В дальнейшем ты должен будешь способен используя файл OTTL.ebnf создать лексер, парсер и абстрактное синтаксическое дерево (AST)
на языке RUST с применением Chumsky и Logos.
Написать тесты для них используя документацию по OTTL: https://github.com/open-telemetry/opentelemetry-collector-contrib/blob/main/pkg/ottl/README.md
и все вложенные ссылки до 2-го уровня.
